# Ashen Depths

A roguelike descent through a burning dwarven hold. The whole game lives in `docs/` and runs as a static site
(no build step): open `docs/index.html` through any web server.

## Play it full screen on a phone

The game is served with GitHub Pages from the `docs/` folder. To turn that on:
**Settings → Pages → Build and deployment → Deploy from a branch →** pick this branch and the `/docs` folder.

- **iPhone / iPad:** open the Pages link in Safari, tap **Share → Add to Home Screen**, then launch it from the
  home screen. It runs full screen and in landscape, like an app. (iPhone Safari does not allow full screen for
  web pages any other way.)
- **Android:** tap **Full screen** on the title screen, or use the browser menu's **Add to Home screen / Install**.
